# Project Glossary — นิยามคำศัพท์มาตรฐานของโปรเจกต์

| คำศัพท์ (Term) | คำจำกัดความและกฎการทำงาน (Definition & Rules) |
| :--- | :--- |
| **Single Custom R15 Rig** | โครงกระดูกตัวละครมาตรฐานเดียวของเกมที่ใช้แทนโมเดลอวาตารของผู้เล่นทุกคน ปรับเฉพาะ `HeightScale` และ `WidthScale` ตามการ์ดนักเตะ และล็อกใบหน้าสไตล์อนิเมะ |
| **Hex-Cage Arena** | สนามแข่งขันกรง 6 เหลี่ยม 3D ล้อมรอบด้วยกำแพงและเพดานตาข่ายที่สะท้อนลูกบอลได้ทุกทิศทาง พร้อมจุด `Rebound Markers` เรืองแสง |
| **Pinball Bumpers** | แผงสะท้อนความยืดหยุ่นสูงบริเวณมุมกรง (`Restitution = 1.25`) สำหรับเตะชิ่งเปลี่ยนทิศทางความเร็วสูง |
| **360° Goal Zone** | พื้นที่ด้านหลังประตูที่ตั้งยื่นออกจากผนังหลัง `14 Studs` ให้เลี้ยงอ้อมหรือเตะชิ่งกำแพงหลังโกลได้ |
| **Elevating Ramps** | ทางลาดเอียง `25 องศา` บริเวณขอบสนามซ้าย-ขวา เมื่อเตะบอลผ่านจะได้รับแรงยกตัว (`Upward Impulse`) ลอยโด่งเข้ากลางสนาม |
| **Choice Duel (1v1 Duel)** | ระบบดวลตัวต่อตัวเมื่อผู้ถือบอลเข้าประชิดกองหลังในระยะ `<= 6 Studs` ล็อกผู้เล่นทั้งสองฝ่ายเข้าสู่หน้าจอกดเลือก Choice ตามตำแหน่ง (`0.8 วินาที` หรือลดเหลือ `0.45 วินาที` หากติด Mistake) |
| **Shooting Zone** | ระยะทำการยิงที่ระบบกำหนด ผู้เล่นฝ่ายรุกจะเห็นและกดชอยส์ `Snap Shot` ได้เฉพาะเมื่ออยู่ในโซนนี้เท่านั้น |
| **Shot Block** | ชอยส์เกมรับของกองหลังสำหรับดักทาง `Snap Shot` ปรากฏให้เลือกเฉพาะในหน้าจอดวล 1v1 (`Choice Duel`) เท่านั้น |
| **Parry System** | ระบบสกัดบอลเมื่อลูกส่งหรือลูกยิงพุ่งผ่านรัศมีรอบตัวกองหลัง (`Intercept Radius: 5 Studs`) โดยไม่ตัดเข้าหน้าจอดวล กองหลังต้องกดปุ่ม `Parry / Intercept` (`KeyCode.F`) ภายในหน้าต่าง `0.35 วินาที` |
| **Mistake Mechanics** | ระบบบทลงโทษจากการเคลื่อนที่ผิดพลาดก่อนเข้าดวล ทั้งฝั่งครองบอล (`Stamina Exhausted < 15%`, `Bad First Touch`, `Sharp Turn Off-Balance`) และฝั่งไม่ครองบอล (`Missed Slide Recovery`, `Back-Turned Positioning`, `Sprint Overshoot`) |
| **Player Cards (Tier B / A / S)** | การ์ดนักเตะที่กำหนดสัดส่วนความสูง, สเตตัสพื้นฐาน (ต่างกันไม่เกิน 15%), ชอยส์พิเศษ (`Signature Duel Choice` ช่องที่ 5), `Card Trait` และจำนวนท่าคัตซีนชนะดวล (1–3 ท่าตาม Tier) |
| **Battle Threads** | อุปกรณ์สวมใส่ประเภทชุดแข่งแนวสตรีท/อนิเมะ (ไม่มีระบบรองเท้าสตั๊ด) มีช่องใส่หิน Trait (`Trait Slots`) 1–2 ช่องตามระดับความหายาก |
| **Trait (Soul Stone)** | ไอเทมสกิลสวมใส่ในช่องของ `Battle Threads` ที่มอบผลลัพธ์การันตี 100% ตามจังหวะ แต่ทุกชิ้นต้องมี **Cooldown** ฝั่ง Server เสมอ |
| **Mutated Gear** | ชุด `Battle Threads` ที่ติดสถานะกลายพันธุ์ (เช่น `Golden Aura`, `Void Glitch`, `Blood Moon Flame`) ช่วยเพิ่มเอฟเฟกต์ VFX, มูลค่าการเทรด และบัฟคูณรางวัลหลังจบแมตช์ (`Cash Multiplier x1.5–x5`, `EXP Multiplier x1.5–x3`) โดยห้ามเพิ่มสเตตัสในสนามเด็ดขาด |
| **FC27 Free Kick Control** | ระบบยิงลูกนิ่งและฟรีคิก 3 ขั้นตอน: เล็งทิศทาง (`Aim Line`), เลือกจุดสัมผัสบอล (`Ball Spin Selector` สำหรับ Curve / Dipping / Knuckleball) และกดแถบจังหวะ 2 ครั้ง (`Timed Power & Accuracy Bar`) |
| **UIManager** | ตัวควบคุมหน้าจอหลักตัวเดียว (`src/client/ui/UIManager.luau`) ที่บริหารโหมด `LOBBY_MODE` และ `MATCH_MODE` ไม่ให้หน้าต่าง UI เปิดซ้อนทับกัน |
