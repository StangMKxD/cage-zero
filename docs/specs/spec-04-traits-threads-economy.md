# Spec 04 — Trait, Battle Threads, Mutations และตลาด (Phase2 draft)

Q22เปลี่ยนเกมเพลย์เป็นฟุตบอลต่อเนื่อง; เอกสารนี้ไม่อนุมัติเปิดเศรษฐกิจในPhase1 และต้องอ่านแผนPhase2เจ้าของก่อนใช้รายละเอียดbaselineด้านล่าง

## 1. Skill inventory แยกจาก Trait

- ต้องมีสุ่มตัวละคร/สุ่มสกิล/สุ่มเอฟเฟคตามแผนPhase2 โดยธุรกรรมมาก่อน ownership/รายชื่อท่า/ดาว/ของซ้ำ/pity/ratesยังต้องgrill
- Skill Moveใช้ระบบ3ช่องจากPhase1 มีcost/CD/recoveryและถูกสกัดได้ ไม่ใช้Signature Choiceหรือผลชนะอัตโนมัติ
- Trait/Soul StoneของBattle Threadsเป็นขอบเขตPhase2แยกจากSkill3ช่อง ผลที่คงไว้ต้องทบทวนกับเกมใหม่ก่อนimplementation ไม่คัดLaser Guided Pass/Miracle Finishที่เคยตัด หรือIron Lockdownที่อ้างชนะChoiceกลับมา
- Traitที่ยังเลือกไว้ต้องมีคูลดาวน์Server ข้อความการันตีในbaselineไม่อนุมัติI-frame/auto-catch/ผลชนะสกัดในDemo

## 2. อุปกรณ์สวมใส่ "Battle Threads" (ไม่มีระบบรองเท้าสตั๊ด)
- **ห้ามสร้างระบบรองเท้าสตั๊ด (No Boots/Cleats System)** อุปกรณ์สวมใส่มีเพียงชุด **"Battle Threads"** เท่านั้น
- เป็นชุดสวมใส่เพิ่มความเท่ (เสื้อคลุมสตรีท, ชุดเกราะเบาอนิเมะ, เสื้อแจ็กเก็ตเรืองแสง)
- มีช่องใส่หิน Trait (`Trait Slots`) `1–2 ช่อง` ตามระดับความหายากของชุด
- สามารถถอดเปลี่ยนชุดและถอดหิน Trait ไปวางขายหรือแลกเปลี่ยนใน `TradeMarketService` ได้

## 3. ระบบ Mutated Gear (ของกลายพันธุ์เพื่อความเท่และคูณฟาร์ม - Zero Pay-to-Win)
- ชุด `Battle Threads` มีโอกาสสุ่มติดสถานะกลายพันธุ์ (`Golden Aura`, `Void Glitch`, `Blood Moon Flame`) จากการเล่นผ่านอีเวนต์พิเศษ
- **ผลลัพธ์ที่อนุญาต:**
  1. เพิ่มเอฟเฟกต์ออร่ารอบตัวและรอยเท้าเรืองแสงเวลาวิ่งในสนาม (VFX)
  2. เพิ่มมูลค่าราคาขายและความต้องการในตลาดเทรดของผู้เล่น
  3. สุ่มมอบบัฟ **คูณเงิน (`Cash Multiplier x1.5 ถึง x5`)** หรือ **คูณค่าประสบการณ์ (`EXP Multiplier x1.5 ถึง x3`)** หลังจบแมตช์เท่านั้น
- **ข้อห้ามเด็ดขาด:** ห้ามเพิ่มความเร็ววิ่ง พลังยิง หรือสิทธิ์ชนะการปะทะในสนามเด็ดขาด

## 4. ระบบตลาดแลกเปลี่ยน (`TradeMarketService`)
- **Market Booth:** ตั้งแผงขายชุด `Battle Threads`, หิน `Trait` และการ์ดนักเตะด้วยเงิน `Cash` (6 ช่องต่อแผง)
- **P2P Trade 2 ชั้น:** ผู้เล่นทั้งสองฝั่งต้องกด `1. Lock Offer` ก่อน (หากมีการเปลี่ยนของ สถานะ Lock จะหลุดทันที) จากนั้นปุ่ม `2. Confirm Trade` จะนับถอยหลัง `3 วินาที` พร้อมระบบล็อกธุรกรรม (`Atomic Transaction / Anti-Dupe Lock`) บน Server
