# Spec 02 — ระบบดวล 1v1 (Choice Duel), ตำแหน่ง, ข้อผิดพลาด และระบบ Parry

## 1. การแบ่งตำแหน่งและชุด Choice ประจำตำแหน่ง (Position-Based Choices)
ผู้เล่นเลือกตำแหน่งก่อนเริ่มแมตช์ (`Forward`, `Midfielder`, `Defender`) การดวล 1v1 (`Choice Duel`) จะเกิดขึ้นเฉพาะเมื่อผู้ถือบอลเข้าประชิดกองหลังในระยะ `<= 6 Studs`:

| ตำแหน่ง / สถานะ | ตัวเลือก Choice ในหน้าจอดวล 1v1 | เงื่อนไขการชนะทาง (Resolution Matrix) & ข้อจำกัด |
| :--- | :--- | :--- |
| **กองหน้า (`Forward` - ครองบอล)** | 1. `Speed Burst` (แตะกระชาก)<br>2. `Tech Nutmeg` (หลอกล่อ/แตะลอดขา)<br>3. `Quick Pass` (จ่ายด่วน)<br>4. `Snap Shot` (ยิงฉับพลัน)<br>5. `[Signature Choice]` (ตามการ์ดนักเตะ) | - `Speed Burst` ชนะ `Jockey`, แพ้ `Hard Tackle`<br>- `Tech Nutmeg` ชนะ `Hard Tackle`, แพ้ `Jockey`<br>- **`Snap Shot` แสดงให้กดได้เฉพาะเมื่ออยู่ในระยะยิง (`Shooting Zone`) ที่ระบบกำหนดเท่านั้น!** ชนะ `Hard Tackle`/`Jockey`, แต่แพ้ `Shot Block` |
| **กองกลาง (`Midfielder` - ครองบอล)** | 1. `Through Pass` (แทงทะลุช่อง)<br>2. `Wall Bounce Pass` (ชิ่งกำแพงหนี)<br>3. `Lob Pass` (ตักบอลข้ามหัว)<br>4. `Body Feint` (โยกหลอกเลี้ยงผ่าน)<br>5. `Snap Shot` (เฉพาะในระยะยิง) | - `Wall Bounce Pass` และ `Lob Pass` ชนะ `Hard Tackle`<br>- `Through Pass` ชนะ `Shot Block`, แพ้ `Jockey` ที่ดักทางส่ง<br>- `Body Feint` ชนะ `Jockey`, แพ้ `Hard Tackle` |
| **กองหลัง (`Defender` - ฝ่ายรับในระยะดวล)** | 1. `Hard Tackle` (สไลด์ตัดบอล)<br>2. `Jockey / Intercept` (ยืนคุมเชิงดักเลี้ยงและดักส่ง)<br>3. `Shot Block` (ทิ้งตัวบล็อกวิถียิง)<br>4. `[Signature Def Choice]` (ตามการ์ด) | - **ชอยส์ `Shot Block` จะปรากฏเฉพาะตอนเข้าหน้าจอดวล 1v1 ในระยะประชิดเท่านั้น** ใช้ดักทางเมื่อคิดว่าฝ่ายรุกจะกด `Snap Shot`<br>- หากเดาทางถูก ฝ่ายรับจะแย่งบอลมาครองได้ทันที |

## 2. ระบบ Parry สกัดบอลส่ง/ลูกยิง (เมื่อบอลพุ่งผ่านนอกการดวล)
- **เงื่อนไขการทำงาน:** เมื่อคู่แข่งกดส่งบอลหรือยิงบอลจากระยะไกล แล้ววิถีลูกบอลพุ่งเข้ามาในรัศมีรอบตัวกองหลัง (`Intercept Radius: 5 Studs`) **เกมจะไม่ตัดเข้าหน้าจอดวล Choice**
- **หน้าต่างการกด (`0.35 วินาที`):** หน้าจอกองหลังจะขึ้นวงแหวนเตือนสีเหลืองที่เท้า กองหลังต้องกดปุ่ม `Parry / Intercept` (`KeyCode.F` หรือปุ่มบนจอ) ให้ตรงจังหวะ:
  - **Perfect Parry (กดตรงจังหวะ):** กองหลังยื่นเท้าดูดบอลลงพื้นและได้ครองบอลสวนกลับทันที
  - **Early / Late (กดผิดจังหวะ):** บอลจะแฉลบหรือลอดขาผ่านไปหาเป้าหมายของฝ่ายรุก และกองหลังติดอนิเมชันเสียหลัก `0.5 วินาที`

## 3. ระบบข้อผิดพลาด (Mistake Mechanics) ทั้งคนครองบอลและคนไม่ครองบอล

| ฝั่งผู้เล่น | พฤติกรรมที่ทำให้เกิดข้อผิดพลาด (Mistake Trigger) | บทลงโทษในการดวล (Penalty) |
| :--- | :--- | :--- |
| **คนครองบอล (On-Ball)** | 1. **Stamina Exhausted:** กดวิ่งสปรินต์ค้างจนหลอด Stamina ต่ำกว่า 15% ก่อนเข้าดวล<br>2. **Bad First Touch:** รับบอลที่ส่งมาแรงโดยไม่กดชะลอความเร็ว<br>3. **Sharp Turn Off-Balance:** หักเลี้ยวกลับหลัง 180 องศากะทันหันก่อนถูกประชิดตัว | - เวลาเลือก Choice ลดลงจาก `0.8 วิ` เหลือ `0.45 วิ`<br>- ชอยส์ `Tech Nutmeg` ถูกล็อกใช้งานไม่ได้ในจังหวะนั้น (แสดงไอคอนแม่กุญแจสีแดง)<br>- หากเลือกชอยส์เสมอกับกองหลัง คนครองบอลจะเสียบอลทันที |
| **คนไม่ครองบอล / กองหลัง (Off-Ball)** | 1. **Missed Slide Recovery:** กดสไลด์หรือกด Parry วืดก่อนเข้าดวล<br>2. **Back-Turned Positioning:** หันหลังให้ผู้ถือบอลในจังหวะที่เข้าสู่ระยะดวล<br>3. **Sprint Overshoot:** วิ่งพุ่งเข้าใส่ด้วยความเร็วสูงสุดโดยไม่กดชะลอคุมเชิง | - ชอยส์ `Jockey / Intercept` ถูกล็อก (เหลือแค่เสี่ยงทาย `Hard Tackle` หรือ `Shot Block`)<br>- โอกาสโดนแตะลอดขา (`Nutmeg`) เพิ่มขึ้น และติดอนิเมชันล้มนานขึ้น `0.5 วินาที` |
