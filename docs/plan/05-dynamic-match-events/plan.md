# MODULE 05: `05-dynamic-match-events` (3 อีเวนต์สนาม: เสาขวาง, หลุมดำ, สตรีทบราซิล)

## 1. เป้าหมาย (Objective)
สร้างระบบจัดการอีเวนต์กลางแมตช์ทั้ง 3 แบบ (`Pillar Lockdown`, `The Blackout Void`, `Favela Alleyway`) ให้ทำงานได้ลื่นไหลและรองรับผู้เล่นทุกคนในสนามพร้อมกัน

## 2. เอกสารสเปกที่อ้างอิง (Referenced Specs)
- `docs/specs/spec-01-cage-and-events.md`
- `docs/design/architecture-and-network.md`

## 3. ห้ามทำเกินขอบเขต (Out of Scope)
- ห้ามสร้างอีเวนต์อื่นนอกเหนือจาก 3 อีเวนต์ที่กำหนดไว้ในสเปก

## 4. เกณฑ์ตรวจรับสำหรับ Codex (TDD Acceptance Criteria)
1. ในอีเวนต์หลุมดำ ขอบกรงต้องมองไม่เห็นด้วยตาเปล่า แต่ยังสะท้อนลูกบอลได้เหมือนเดิม และเห็นโกล/บอล/ผู้เล่นชัดเจน
2. ในอีเวนต์ตรอกบราซิล ตำแหน่งของ NPC คนเดินผ่านต้องตรงกันในหน้าจอของผู้เล่นทุกคน (Synced) และเฟรมเรตไม่ตก
