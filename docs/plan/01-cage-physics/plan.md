# MODULE 01: `01-cage-physics` (สนามกรง 5 มิติ & ฟิสิกส์การชิ่งกำแพง/เพดาน)

## 1. เป้าหมาย (Objective)
สร้างสนามกรง 6 เหลี่ยม 3D พร้อมเพดานตาข่าย, แผงดีด Bumper, โซนหลังโกล 360 องศา, ทางลาดริมเส้น (Elevating Ramps) และระบบฟิสิกส์ลูกบอลชิ่งสะท้อนฝั่ง Server

## 2. เอกสารสเปกที่อ้างอิง (Referenced Specs)
- `docs/specs/spec-01-cage-and-events.md`

## 3. ห้ามทำเกินขอบเขต (Out of Scope)
- ห้ามเพิ่งใส่ระบบอีเวนต์เสาผุดหรือหลุมดำในโมดูลนี้

## 4. เกณฑ์ตรวจรับสำหรับ Codex (TDD Acceptance Criteria)
1. ลูกบอลชิ่งผนังกรงทุกด้านและเพดานได้อย่างแม่นยำ ไม่ทะลุออกจากกรง (Zero Clipping) แม้เตะด้วยความเร็วสูงสุด
2. เมื่อเลี้ยงบอลขึ้นทางลาดริมเส้นแล้วเตะ ลูกบอลลอยโด่งเข้ากลางสนามตามค่าที่ตั้งไว้
