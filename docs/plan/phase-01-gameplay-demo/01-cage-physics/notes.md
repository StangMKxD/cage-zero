## ข้อสรุปฟีเจอร์จากการ grill — Accepted design; เลือก phase แล้ว ยังไม่ implement
- **N-07 สถานะแยกกัน:** ผู้ใช้ตกลงกติกา Q1–Q38 และเลือก Phase 1 แล้ว บันทึกเป็น design/scope decisions ไม่ใช่อนุมัติ implementation; mapping อยู่ roadmap และ phase plan เรื่องที่ยังเปิดให้ grill เมื่อใกล้ทำ
- **N-08 โหมด/ทีม (Q16/26):** คง 3v3/4v4 และ Training ตัด 1v1v1 ออก จำนวนทีมรวมโกล: 3v3=สนาม2+โกล1, 4v4=สนาม3+โกล1
- **N-09 โกล (Q18/22/27):** ถ้าไม่มีคนเลือกใช้ AI ตลอดเกม คนรับตำแหน่งแทน AI ได้ตอนหยุดเล่น; รับ/ปัดด้วยมือและพุ่งเซฟเฉพาะเขตโทษ นอกเขตเหมือนผู้เล่นสนาม คนและ AI ใช้กติกาเดียวกัน
- **N-10 เล่นอิสระ (Q1/20):** รับ movement/เลี้ยง/Dash/Feint/Slide/ยิงส่ง/กระโดด/Header/Volley จาก sandbox เป็นฐานฟีเจอร์ ยิงปกติไม่ล็อกโซน ชาร์จขณะเคลื่อนที่/กลางอากาศได้ แต่ขณะชาร์จและเคลื่อนที่ต้องช้าลง; ท่าเสกหุ่น/reset ด้วยมือเป็นเครื่องมือซ้อม
- **N-11 เริ่มดวล (Q6/13/17):** เข้าเขตเกิด Duel Event อัตโนมัติ Feint ใช้หลบระยะ; สโลว์ทั้งสนามสั้น ๆ ตอนเปิดแล้วกลับปกติ นาฬิกาเดินต่อ คนอื่นเคลื่อนที่ได้แต่แทรกคู่ดวลไม่ได้
- **N-12 Choice ใหม่ (Q21/23/29):** ดวลเพื่อเลี้ยงผ่านเท่านั้น ตัด Snap Shot/ชอยส์ยิงและส่งทุกแบบ; พื้นฐานร่วมทุกตำแหน่ง: กระชาก/โยกหลอก/ลอดขา ฝ่ายรับ: พุ่งสกัด/คุมเชิง/ดักทางเลี้ยง; ตารางชนะทางต้องจัดให้สอดคล้องตอนทำรายละเอียด
- **N-13 ผลดวล (Q25/28/30):** ผู้ชนะครองบอลพร้อมคัตซีนเฉพาะคู่ดวล ผู้แพ้สตั้นสั้น ๆ หลังคืนการควบคุม; ป้องกันการแทรกระหว่างดวล/คัตซีน คนอื่นเล่นต่อได้ และคัตซีนส่วนตัวไม่หยุดนาฬิกา
- **N-14 เกมรับนอกดวล (Q5/10):** ยกเลิก timed Parry นอกดวล ใช้กระโดดบล็อก บอลเด้งเป็นบอลอิสระ ไม่ได้ครองอัตโนมัติ; ไม่ลบเกมรับใน Choice Duel
- **N-15 เวลา (Q2/7/14/17/30):** เวลาปกติไม่เกิน 5 นาทีของเวลาเล่น ไม่ใช่เพดานเวลาจริงรวมทุกช่วง; หยุดช่วงดีใจหลังประตูและเตรียมฟรีคิก/จุดโทษ เดินต่อในสโลว์เปิดดวลและคัตซีนเฉพาะคู่
- **N-16 เสมอ (Q3/8/11/15):** จบเวลาปกติเลือก Golden Goal/จุดโทษ/จบเสมอ/ต่อเวลา ทุกคนต้องเห็นตรงกันจึงต่อ มิฉะนั้นจบเสมอ; Golden Goal/ต่อเวลามีเพดานของตนเอง หากหมดแล้วยังเสมอจบเสมอทันที ไม่โหวตวน
- **N-17 Shootout (Q31):** ทีมกำหนดลำดับ ยิงสลับจำนวนรอบเท่ากัน หากยังเสมอ Sudden Death โดยให้โอกาสเท่ากัน ไม่ผูกกับการยิงครบสมาชิกเพราะอาจมี GK AI
- **N-18 ฟาวล์/ลูกนิ่ง (Q4/12/19):** Slide โดนคนก่อนบอลเป็นฟาวล์ นอกเขตฟรีคิก ในเขตจุดโทษ; ใช้ FC27 aim/spin/timing ตามระบบลูกนิ่งเดิม ยังไม่เพิ่มใบเหลือง–แดง
- **N-19 สกิลที่ตัด (Q24):** ไม่เก็บสกิลยิง/ส่งจากการ์ดและ Trait; ต้อง diff รายชื่อ/บัฟที่ได้รับผล ไม่ลบทั้งการ์ด/ชุด/Trait หรือสกิลเลี้ยง–รับโดยอัตโนมัติ
- **N-20 เอฟเฟค (Q32 แก้):** เหลือสองชุด: ยิง+ส่ง และวิ่ง+กระโดด+โยก หนึ่งชุดได้ครบ action ของหมวด เลือกสวมสองหมวดต่างธีมได้ ไม่แยกโยกเป็นหมวดสุ่มต่างหาก
- **N-21 สุ่ม/ของซ้ำ (Q33–37):** เลือกหมวดก่อนสุ่ม ใช้ Cash เดิม rarity ต่างด้านภาพ ไม่มีค่าสเตตัส; ของซ้ำเก็บก่อน เลือกเก็บขายหรือสลายเป็นแต้มเอง เมื่อสลายชิ้นนั้นถูกใช้ไป แต้มใช้แลกชุดที่ต้องการ
- **N-22 ตลาด (Q38):** เอฟเฟคขายเป็นชุดผ่านแผง Cash เท่านั้น ไม่มี P2P สำหรับเอฟเฟค; P2P ของสินค้ากลุ่มเดิมยังไม่ถูกสั่งลบทั้งเกม
- **N-23 คงของเดิม:** Hex-Cage/เพดาน/bumper/ramp/back zone, Custom R15, Mistake, การ์ด/Tier/คัตซีน, อุปกรณ์/Trait ที่ไม่ถูกตัด, Mutations แบบไม่เพิ่มพลังสนาม, กาชาเดิม/เศรษฐกิจ/รางวัล, ตลาดเดิม, อีเวนต์สามแบบและ UI flow ยังคงเป็น backlog ไม่ถือว่าหายไปเมื่อไม่เลือก demo
- **N-24 เปรียบเทียบเอกสาร:** ข้อสรุปจากผู้ใช้ด้านบน supersede เฉพาะส่วนที่ระบุของ PRD/spec เดิม ไม่ใช่แทนที่ทั้งฉบับ; เลือก phase แล้ว แต่ยังไม่ sync PRD/spec/API ทุกระบบ; แผนลงมือต้อง sync เฉพาะส่วนที่ทำกับ decisions นี้ก่อน และไม่บังคับลงรายละเอียด Phase 2 ตอนนี้
- **N-25 ค่าจูน:** ตัวเลขความเร็ว/แรง/ระยะ/cooldown/เรตและราคาไม่ล็อกในการจัด module catalog ตัวเลขในรายงาน sandbox ไม่ใช้แทนค่าปัจจุบันโดยไม่ตรวจ source/config

- **N-26 Phase selection:** คงขอบเขตผู้ใช้เลือกเดิมครบทั้งหมด แต่ย้ายแผนอยู่ใต้ phase จริง ใช้เลข/ชื่อโฟลเดอร์แผนโดยตรง รายการอยู่ phase plan ทั้งสองแห่ง ไม่มีรหัส feature แยกเพื่อควบคุมงานอีกชุด
- **N-27 Dependency boundary:** Phase 1 มีฉากฝึกเพื่อทดสอบโกล/ลูกนิ่ง/อีเวนต์และ UI ที่เกี่ยวข้อง ไม่รวม full match clock/result/rewards หรือหน้าระบบ Phase 2; ถ้าต้องขยายให้เสนอ scope change ไม่ดึง แมตช์เต็ม เข้ามาเอง
- **N-28 Player gacha/stats (2026-10-20):** ผู้ใช้เพิ่มสุ่มนักเตะ มีระดับและ stats เช่นพลังยิง/ยิงโค้ง/ความเร็ว/พุ่งสกัด/เลี้ยงบอลใน Phase 2 สุ่มนักเตะ/collection เท่านั้น เป็น base stats แยกจากสกิลยิง/ส่งที่ตัด; ยังไม่ยกเลิกข้อจำกัดสมดุลเดิมหรือสรุปสูตร/เรต/ราคา ค่อย grill เมื่อเปิด phase

- **N-29 Plan layout:** 2026-10-20 ย้ายโฟลเดอร์แผนเข้า phase และเรียงเลขภายใน phase; แยกการ์ด/collection/meta UI/full match ที่คร่อมของเก่าไป Phase 2 รายงาน baseline เก็บอยู่กับโฟลเดอร์ที่ย้าย ไม่มี source implementation เปลี่ยน

- **N-30 Player stats:** ผู้ใช้ย้ำ Phase 2 ให้สุ่มตัวละครมี stats ไม่มาก เช่นยิงแรง/ยิงโค้ง/วิ่งเร็ว/พุ่งสกัด/เลี้ยงบอล; เก็บรายการสุดท้ายและรายละเอียดไว้ grill เมื่อเปิดแผน ไม่ล็อกสูตรตอนนี้

- **N-31 UAT/transactions/Git:** ผู้ใช้เพิ่ม Phase 1 09-uat, Phase 2 transactions ก่อนกาชา/เศรษฐกิจ/ตลาดและ full UAT ท้ายสุด พร้อมอนุญาต commit/push เอกสารรอบนี้; implementation ยัง PENDING
