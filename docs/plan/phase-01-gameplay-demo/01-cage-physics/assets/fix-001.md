### F-03 (P1) — Swept-Sphere Post Edge/Corner Continuous TOI Solver
- **ปัญหาเดิม:** โค้ดเดิมตรวจเฉพาะระยะห่างที่จุดเข้า expanded box ($t_{Enter}$) และจุดสิ้นสุด ($t = 1.0$) หากการเคลื่อนที่เข้าและออกจาก corner cylinder ในระหว่าง time-step candidate จะถูกทิ้ง ทำให้เกิดการ tunneling ผ่านขอบเสา ดังที่แสดงในตัวอย่างของ Codex (Start $(-15, 5, -118.6)$, Velocity $(180, 0, 0)$, dt $1/30$, Radius $1.25$ ข้ามเสา $X \in [-12.4, -11.6]$)
- **การแก้ไข:**
  1. ในฟังก์ชัน `sweepSphereAgainstSurface`: เมื่อ ray พุ่งผ่าน interval $[t_a, t_b]$ ของ expanded box แต่จุดเข้าอยู่นอกทรงกระบอกมุม ($d(t_a) > r$), โค้ดจะใช้ **Golden-Section Search** เพื่อหาจุดต่ำสุดของระยะห่าง $t_{min} \in [t_a, t_b]$ บนฟังก์ชันระยะห่างแบบนูน (convex distance function)
  2. หากระยะห่างต่ำสุด $d(t_{min}) \le r + 1e-4$, ใช้อัลกอริทึม **Bisection 16 รอบ** ค้นหา Time of Impact ($t_{hit}$) ที่แน่นอนบนช่วง $[t_a, t_{min}]$ ที่ทำให้ $d(t_{hit}) = r$
  3. คำนวณ surface normal ที่แท้จริงจากจุดกระทบเทียบกับขอบ/มุมของเสา
  4. พิสูจน์จริงใน Roblox Studio Edit DataModel ด้วย counterexample ของ Codex:
     - ก่อนแก้: บอลเคลื่อนผ่านทะลุเสาไปถึง $X = -9$ โดย `hitTag = nil`
     - หลังแก้: ตรวจจับการชนที่ $t = 0.308334$, จุดชน $X = -13.15, Z = -118.80$, Normal $= (-0.6, 0, 0.8)$, Velocity สะท้อนพุ่งไปข้างหน้าสู่สนาม ($newVel.Z = +152.06 > 0$) และลดความเร็วแกน X จาก 180 เหลือ 44.35
  5. บรรจุ regression test นี้ไว้ใน `TC-F05-05` ทั้งฝั่งเสาซ้ายและเสาขวา (Mirrored)
