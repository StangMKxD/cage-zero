## 1. Executive Summary & Root Cause Fixes

Following live playtest feedback and Owner directives, all requested gameplay systems have been implemented, synced to Studio DataModel, and verified in both Edit and Play modes:

1. **Floaty Pass System Overhaul ("กด E ให้ไวกว่าระยะวิ่งนิดนึง และลอยๆ หน่อย"):**
   - **Tap Pass Speed:** `PASS_GROUND_TAP_SPEED = 36.0` studs/s (outpaces sprint speed of 32.0 studs/s).
   - **Full Charged Pass Speed:** `PASS_GROUND_FULL_SPEED = 58.0` studs/s.
   - **Floaty Low Gravity:** `PASS_GRAVITY_ACCELERATION_Y = -22.0` studs/s² (soft, floaty arc).
   - **Floor Chip Loft:** When aiming down toward the turf (`aimDir.Y < -0.12`), lofted rebound bounce is dynamically applied (`bounceUp = |aimDir.Y| * passSpeed * 0.75`), allowing teammates to intercept and receive naturally.

2. **Shooting Speed Reduction (-2 studs) ("ปั่นกับยิงธรรมดามันเร็วไป ปรับช้าลง 2 studs"):**
   - Straight Shoot: `125.0` ➔ `123.0` studs/s.
   - Finesse Curve: `82.0` ➔ `80.0` studs/s.
   - Trivela Curve: `84.0` ➔ `82.0` studs/s.
   - Unified Curve: `95.0` ➔ `93.0` studs/s.

3. **Power Gauge & Multiplier Re-scale ("ไล่ระดับเกจการยิงใหม่ ให้ห่างกันเยอะๆ ระหว่าง % การง้าง"):**
   - **Range:** Starts at quick tap 20% (`CHARGE_MIN_POWER = 0.20`), scaling up to 100% MAX (`CHARGE_MAX_POWER = 1.00`).
   - **Spread Ratio:** `2.38x` physical & visual spread:
     - 20% Tap = `0.65x` power multiplier (2 gauge segments lit).
     - 50% Mid = `0.99x` power multiplier (5 gauge segments lit).
     - 100% MAX = `1.55x` power multiplier (10 gauge segments lit, Fire MAX tier).
   - **HUD Visuals:** 10 tapered vertical segments with distinct tier colors (Cyan 20–49%, Yellow 50–74%, Orange 75–99%, Fire MAX 100%).

4. **Skill Z (Slot 1) vs Skill X (Slot 2) Physical Separation ("ท่า z แตะบอลไปข้างหน้าไม่ต้องตาม แต่ ท่า x ให้ตามบอลไปด้วย"):**
   - **Key Z (Slot 1):** Taps ball forward `5.5 studs` into open space; character does NOT burst (`distMovedSlot1 = 0.0 studs`).
   - **Key X (Slot 2):** Knocks ball forward `4.2 studs` and physically surges the player character forward using `LinearVelocity` (`KNOCK_ON_BURST_SPEED = 28.0` studs/s for `0.26s`, verified character displacement `8.55 studs`) to follow and reclaim possession.

5. **Movement-Driven Lateral Direction & Sagittal Animation Mirroring ("skill ที่โยกซ้ายขวาต้องมีผลกับ movement ไม่ใช่ล็อคไว้"):**
   - Feint/Cut direction dynamically reads `A` key / leftward movement (`side = -1`) and `D` key / rightward movement (`side = 1`).
   - Cuts at `(flatFwd * 0.55 + rightVec * (side * 0.85)).Unit`.
   - Left feint passes `chosenFoot = "Left"`, which triggers `PlayerActionPoseConfigs.MirrorPoseSagittal(rawPose)`, inverting sagittal joint axes on Left Shoulder, Right Shoulder, Left Hip, and Right Hip (verified live Motor6D transform differentials).

6. **Zero Skill Cooldowns (Pure Stamina Gate) ("skill ไม่มี cooldown อิงตาม stamina เลย กดได้ตลอด"):**
   - All 7 skills in `SkillMoveConfigs.Catalog` set to `cooldownSec = 0.0` and `commonRecoverySec = 0.0`.
   - Removed cooldown checks from `SkillMoveService.luau`, `BallService.luau`, and `InputController.luau`.
   - Skills can be chained continuously as long as `Stamina >= staminaCost`.

7. **Keybindings & Manual UI Toggle Fix ("ปรับปุ่ม zxc ปุ่ม reset ball เป็นปุ่มอื่น แล้วกด H คู่มือไม่เด้ง ui"):**
   - Skill Slots: `Z`, `X`, `C`.
   - Ball Reset: `R`.
   - Manual UI: `H` (removed duplicate listener from `InputController`, added dynamic modal resolution fallback in `TrainingHUD.ToggleCodex()`, verified live open/close toggle).
