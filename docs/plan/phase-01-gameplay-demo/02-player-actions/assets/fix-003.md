### F-13 — P1: Remote รับ Payload ที่ขาด Metadata และ Legacy ข้าม Validation ได้ (RESOLVED)
- **จุดแก้ไข:** `src/server/services/BallService.luau` (ฟังก์ชัน `HandleActionRequest`)
- **รายละเอียด:**
  - ปฏิเสธ Payload ที่ไม่ใช่ table (เช่น string `"DirectShoot"`) ทันทีด้วยสถานะ `Rejected` และเหตุผล `InvalidPayload` โดยไม่มีการสร้าง intent สุ่มขึ้นมาเอง
  - บังคับตรวจสอบ `intentId`: หากขาด, เป็นค่าว่าง หรือไม่ใช่ string จะถูกปฏิเสธทันทีด้วย `InvalidPayload`
  - ตรวจสอบ `characterGeneration` และ `contextVersion`: ต้องเป็น finite integer ที่มีค่า `>= 1` หากไม่ผ่านจะถูกปฏิเสธด้วย `InvalidPayload`
  - ตรวจสอบความถูกต้องของเวกเตอร์การเล็ง (`aimDirection`) และค่าพลังชาร์จ (`charge`): หากเป็น `NaN` หรือ `+/-Inf` จะถูกปฏิเสธทันทีด้วย `InvalidPayload`
  - ตรวจสอบค่า `phase`: รองรับเฉพาะ `"start"`, `"release"`, `"cancel"` หากส่งค่านอกเหนือจากนี้จะถูกปฏิเสธทันทีด้วย `InvalidPayload`
  - ลบทางเลือก Legacy ที่อนุญาตให้บายพาส validation ออกทั้งหมด ทุกคำขอต้องผ่านสัญญาเดียวที่รัดกุม

### F-14 — P1: Charge / Intent ยังไม่ผูก Action และวงจร Start -> Terminal จริง (RESOLVED)
- **จุดแก้ไข:** `src/server/services/BallService.luau` (ฟังก์ชัน `StartCharge`, `ExecuteKick`, `HandleActionRequest`)
- **รายละเอียด:**
  - ทำการ Latch ข้อมูลตั้งแต่วินาทีแรกที่เริ่มชาร์จ (`phase == "start"`): บันทึก `st.chargeIntentId`, `st.chargeAction`, `st.chargeGeneration`, `st.chargeContextVersion`
  - ป้องกันการเริ่มชาร์จซ้อน: หากผู้เล่นอยู่ในสถานะ `isCharging` อยู่แล้ว คำขอ `StartCharge` ใหม่จะถูกปฏิเสธด้วย `StaleIntent`
  - บังคับความสอดคล้องในจังหวะปล่อย (`phase == "release"`):
    - ต้องมี Active Charge ที่ตรงกับ `intentId` เดียวกัน
    - Action ที่ส่งมาปล่อยต้องตรงกับ `chargeAction` ที่ Latch ไว้ตั้งแต่แรก (เช่น ชาร์จ `DirectShoot` จะส่ง `Pass` มาปล่อยไม่ได้ จะถูกปฏิเสธด้วย `StaleIntent`)
    - ไม่อนุญาตให้ส่ง `release` โดยไม่มีการ `start`
  - คำนวณพลังชาร์จจากเวลาที่เกิดขึ้นจริงบน Server (`elapsed = now - st.chargeStartTime`): Client ไม่ใช่ผู้มีอำนาจตัดสินพลังยิง ป้องกันการปลอมแปลงค่าพลัง
  - เมื่อคำขอผ่านสถานะ Terminal (`release` หรือ `cancel`) จะถูกบันทึกลง `st.terminalIntents` ทันที และปฏิเสธการ Replay คำขอดังกล่าวซ้ำทุกกรณี

     - **Wind-Up (ท่าง้างเท้าชาร์จ):** ขาหลักปักพื้นมั่นคง, ขาขวาง้างไปข้างหลังเต็มวง (`-84°`), แขนซ้ายยกขึ้นสูงเป็นรูปมุมฉาก (`-125°`) ถ่วงสมดุล
     - **Contact & Follow-Through:** ขาขวาเตะเหวี่ยงพุ่งไปข้างหน้าเต็มข้อ (`95°`), ลำตัวเอนหลังเล็กน้อย, แขนกางสมดุล
     - **Miss / Whiff Recovery (รูปที่ 2 Row 3):** หากเตะวืดโดยไม่มีบอลในระยะ ตัวละครจะเหวี่ยงขาเลยระยะ (`115°`) จนเสียหลักหมุนเซ (Off-Balance Stumble) พร้อมลดความเร็วชั่วขณะ (0.35s) โดยไม่มี I-frame
  3. **อ้างอิงรูปที่ 1 Row 3: Curve Shot (ยิงปั่นโค้ง):**
     - **Wind-Up:** กดจุดศูนย์ถ่วงต่ำลง, ลำตัวเอียงไปฝั่งขาหลักอย่างชัดเจน (Roll `-26°`), ขาเตะง้างออกด้านข้าง
     - **Contact & Sweep:** ลำตัวเอียงขนานพื้น, ขาขวากวาดเตะเฉือนตัดหน้าลำตัวเป็นวงโค้ง (`82°` pitch, `-46°` yaw, `32°` roll)
     - **Curve Whiff Recovery:** การปั่นวืดทำให้เกิดแรงเหวี่ยงหมุนบิดตัว (Twisted Follow-through) ต้องดึงสมดุลกลับก่อนออกท่าถัดไป
  4. **อ้างอิงรูปที่ 2 Row 1 & 2: Mid-Air Volley & Acrobatic Bicycle Kick:**
     - **Mid-Air Volley (Row 2):** ลอยตัวกลางอากาศ, ลำตัวเอียงตะแคงข้าง 56 องศา, กวาดขาขวาฟาดลูกบอลในแนวระนาบ (`92°`), แขนกางออกทั้งสองข้าง
     - **Acrobatic Bicycle Kick (Row 1):** ลำตัวหงายหลังกลับหัว 105 องศา, ตีลังกาเตะกรรไกรฟาดลูกบอลข้ามศีรษะลงสู่ตาข่าย (`125°`), จังหวะลงพื้นติด Ground Recovery ยันตัวลุกขึ้น
  5. **อ้างอิงรูปที่ 3 Row 1: Slide Tackle (ทำเฉพาะ Row 1 — ข้าม Row 2 และ Row 3):**
     - **Wind-Up -> Slide (ช่องที่ 2):** ลำตัวลดระดับลงติดพื้นหญ้าจริง -0.92 studs, เอนหลังไถลไปกับพื้น, ขาขวาเหยียดตรงพุ่งไปข้างหน้ากวาดบอล (`88°`), ขาซ้ายพับรองด้านหลัง (`-55°`), แขนซ้ายยันพื้น (`65°`, `-48°`)
     - **Recovery (ช่องที่ 4):** จังหวะยันพื้นลุกขึ้น (Slide Recovery) แขนทั้งสองข้างดันตัวขึ้นจากพื้นหญ้า ลำตัวยกกลับขึ้นสู่ระดับปกติ
     - **กติกาฟุตบอล:** เมื่อสไลด์โดนบอลจะสกัดบอลให้กระดอนหลุด (Deflect) โดยไม่มี Auto-possession, ไม่มี Auto-stun, และไม่สลับทีมบุกจนกว่าจะมีผู้เล่นครองบอลสำเร็จจริง

### 5.6 การแก้ไขข้อติงล่าสุดของ Owner (Curve Plant Leg Grounded, Jump Arm Dislocation Fix, Jump Height Boost, Dash & Soccer Running Polish)
