## 1. สรุปภาพรวมการดำเนินงานรอบ fix-002

ตามคำสั่งของ Owner ใน `HANDOFF.md §6`:
1. **รักษาผลการแก้ไข F-10 ถึง F-19 จากรอบ fix-001 ครบถ้วน 100%:**
   - การไม่ลอยตัวของลูกบอลบนพื้นหญ้า (`clearance = 0.000 studs`)
   - ระบบ Continuous Opponent Contact & Contest ป้องกันการวิ่งทะลุคู่แข่ง
   - Swept Segment High Aerial Jump Block (Y > 3.8 studs)
   - First-time intents preserved
   - Authoritative Server Charge State & numeric/alive validation
   - Edge fall jump rejection, mid-air dash rejection และ takeoff grace period (0.15s)
   - Player lifecycle cleanup on death/respawn และ team context synchronization
   - NaN comparators ใน TestHarness และ teardown cleanup
2. **ปรับปรุงตาม Sandbox Adaptation Directives & แก้ไขข้อบกพร่องที่ตรวจพบในการรีวิว:**
   - **ถอน LobPass ออกจากระบบ:** ลบ Action Type `LobPass` ออกจาก active types, ปลดการผูกปุ่ม `T`, ลบไกด์ `[T] Lob` จาก HUD, และเมื่อมีคำขอ legacy ส่งเข้ามา จะถูกปฏิเสธด้วย `RemovedAction` โดยไม่มีการ mutate สถานะของลูกบอล
   - **รวมระบบส่งบอล 3 มิติ (Single 3D Pass):** รวมการส่งบอลเป็น action เดียว (`Pass` / `GroundPass`) ที่รองรับการชาร์จน้ำหนักและปรับมุมเล็ง 3 มิติ (`PASS_SPEED_MIN = 50.0`, `PASS_SPEED_MAX = 85.0`, `PASS_DEFAULT_SPEED = 75.0`)
   - **เพิ่มระบบสไลด์แย่งบอลฝั่งรับ (Authoritative Defending Slide Tackle):**
     - ผูกเฉพาะโหมดรับ `Defending` (กด `E` หรือคลิกซ้ายเมื่อไม่มีบอล/เป็นฝ่ายรับ)
     - ตรวจสอบสถานะติดพื้น (Grounded check: ปฏิเสธหากตัวละครลอยกลางอากาศ `isCharacterAirborne`)
     - ล็อกทิศทางการสไลด์ตลอดช่วงเวลาสไลด์ (`SLIDE_SPEED = 52.0`, `SLIDE_DURATION_SEC = 0.44`)
     - ตรวจสอบการสัมผัสลูกบอลในระยะ `SLIDE_TACKLE_REACH = 8.5` studs เตะบอลลอยสู่อากาศเป็นลูกฟรีไฟลท์ (`ballState.state = "InFlight"`, ความเร็ว `SLIDE_KICK_SPEED = 94.0`)
     - ปฏิบัติตามกฎข้อบังคับ: **ไม่มอบสิทธิ์การครองบอลอัตโนมัติ (No Auto-Possession)** และ **ไม่สตันคู่แข่งอัตโนมัติ (No Auto-Stun)**
     - **แก้ไข Bug Multi-Frame Re-Kick ใน `StepPhysics`:** เพิ่มตัวแปร `st.slideHitBall` ป้องกันไม่ให้การสไลด์เตะบอลซ้ำทุกเฟรมฟิสิกส์เมื่อบอลยังอยู่ในรัศมี 8.5 studs
     - **แก้ไข Bug Miss Whiff Penalty:** บทลงโทษชะลอความเร็ว (`WALK_SPEED * 0.35`) จะถูกใช้งานเฉพาะเมื่อสไลด์วืด (Miss Whiff) ตาม prototype3 และ HANDOFF §1 เท่านั้น หากสไลด์โดนบอลสำเร็จ จะไม่โดนลงโทษชะลอความเร็ว
   - **แก้ไข Bug Client `RenderStepped` Infinite Loop ใน `InputController.EndSlide()`:**
     - เคลียร์ `isSlidingClient = false` และ `slideEndTimeClient = 0` ทันทีแบบ synchronous ป้องกัน `RenderStepped` เรียก `EndSlide()` ซ้ำซ้อน 18–30 ครั้งต่อเฟรม
     - ปรับความเร็วฟื้นตัวให้ตรงตามสัญญา `Constants.WALK_SPEED * 0.35` (เดิมใช้ผิดเป็น 0.4)
   - **แก้ไข Bug Idempotency & Phase Transition:**
     - บังคับ State Machine แบบทิศทางเดียว (`start` -> `release` หรือ `start` -> `cancel`)
     - เมื่อ Intent จบ Phase ที่เป็น Terminal (`release` หรือ `cancel`) จะบันทึกลง `st.terminalIntents` และปฏิเสธคำขอซ้ำทุกประเภทด้วย `StaleIntent`
     - คำขอแบบ Instant Actions (`Dash`, `DirectionalJump`, `ResetBall`) ถูกล็อกให้ประมวลผลได้เพียงครั้งเดียวต่อ `intentId`
   - **Tapered Segmented Charge Gauge บน TrainingHUD:**
     - ดึงโครงสร้างเกจชาร์จแบบเทเปอร์ 10 ส่วนจาก prototype3 (`KickChargeGaugeBg`, ขนาด `76 x 114` px) ความกว้างเซกเมนต์ไล่ระดับ `{ 16, 20, 24, 28, 32, 36, 40, 44, 49, 56 }` พร้อมเฉดสี เขียว -> เหลือง -> ส้ม -> แดง
     - ซิงก์ค่าตาม authoritative charge ของเซิร์ฟเวอร์ และล้างการแสดงผลอัตโนมัติเมื่อยกเลิก, เปลี่ยนโหมด, เสียชีวิต หรือรีเซ็ต
   - **R6 Slide Animation Provenance:**
     - บันทึกโปรไฟล์แอนิเมชัน `slide` บนโครงสร้าง R6 ด้วย Asset ID `rbxassetid://125750702` พร้อมเอกสาร provenance ชัดเจน
   - **การเลื่อนระบบท่าโยกและลูกชน (Deferred Mechanics):**
     - ท่าโยกหลอก (Body Feint), การจิ้มบอล (Poke Tackle), และการเบียดแย่ง (Shoulder Challenge) ถูกเลื่อนไปดำเนินการใน Module 03 ตามคำสั่งของ Owner อย่างเป็นทางการ
