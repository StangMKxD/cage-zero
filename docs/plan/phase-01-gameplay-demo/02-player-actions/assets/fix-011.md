## 1. Executive Summary & Root Cause Analysis

### 1.1 Defect Description
In Plan 02, curve shot resolution previously switched the kicking foot to the left leg whenever the ball was situated on the left side of the player (`localBallX < 0`). This inverted the spin velocity (`spinY = -spinY`) and caused the R6 animation system to mirror the kick onto the left leg via `MirrorPoseSagittal`. The Owner clarified that the Plan 02 character is **right-foot dominant**:
- **A / Left movement:** selects Finesse shot struck with the inside of the **RIGHT foot** (`spinY = +52.0`).
- **D / Right movement:** selects Trivela shot struck with the outside of the **RIGHT foot** (`spinY = -56.0`).
- **Neutral / A+D:** defaults to Finesse shot struck with the inside of the **RIGHT foot** (`spinY = +52.0`).
- Ball position (whether situated on the left, center, or right) must **not** change the dominant foot, flip spin direction, or mirror the animation to the left leg.

### 1.2 Confirmed Static Root Cause
In `src/shared/configs/PlayerActionPoseConfigs.luau`, `ResolveCurveShot` line 809 previously evaluated:
```luau
-- BEFORE:
local foot: "Right" | "Left" = if ballSide == "Left" then "Left" else "Right"
...
if foot == "Left" then
    spinY = -spinY
end
```
When `ballSide == "Left"`, `foot` was assigned `"Left"`, which inverted `spinY` and propagated to `BallService` (`char:SetAttribute("ResolvedKickFoot", "Left")`), `InputController` preview, and `R6ActionPoseController` (triggering sagittal pose mirroring).

### 1.3 Correction Applied
1. **Right-Foot Dominance Established:** In `PlayerActionPoseConfigs.ResolveCurveShot`, replaced the active auto-left selection with `local foot: "Right" | "Left" = "Right"`. Removed `spinY = -spinY` inversion so the right-foot spin profile is always preserved.
2. **Metadata Retention:** `ballSide` (`"Left"` | `"Right"`) is retained in the returned `ResolvedCurveShot` table as contact metadata.
3. **Seam Agreement:** Client preview, server `ResolvedKickFoot` / `ResolvedCurveStyle`, and `R6ActionPoseController` charge/release animations all agree on `foot = "Right"`.
4. **Airborne RMB Volley Preserved:** Ground curve selection does not replace airborne RMB Volley; in mid-air, RMB remains strictly mapped to `Volley`.
5. **Preserved Invariants:** Preserved fix-010 3D mouse camera aim, character root yaw lock ($F_0$), momentum lock, soft apex curve $[0.90, 1.00]$, grounded possessor BallPop (§ 16), and good ball physics.
