### 2.2 การผูกวิถีการบิน Airborne เข้ากับความเร็วดิ่งจริง (F-28)
- **ไฟล์แก้ไข:** `src/shared/configs/PlayerActionPoseConfigs.luau`, `src/client/character/R6ActionPoseController.luau`, `src/client/character/R6AnimationController.luau`
- **การทำงาน:**
  1. ปรับปรุงลายเซ็นฟังก์ชันใน `PlayerActionPoseConfigs.luau`:
     ```luau
     function PlayerActionPoseConfigs.GetJumpPose(verticalVelocity: number?): R6JointPoseOffsets
     ```
     - แมปค่า $vy = \text{AssemblyLinearVelocity.Y}$ เทียบกับความเร็วอ้างอิง $72.0$ studs/s:
       $$\text{phase} = \text{clamp}\left(0.50 - 0.50 \times \frac{vy}{72.0}, 0.05, 0.95\right)$$
       - **จังหวะพุ่งตัวขึ้น ($vy > 0$):** เฟส $0.05 \dots 0.45$ (คีย์เฟรม 2: Ascent Drive, แขนสองข้างยกขึ้น $53^\circ \dots 110^\circ$, ขาขวาดึงเข่าขึ้นส่งแรง)
       - **จังหวะลอยตัวสูงสุด ($vy \approx 0$):** เฟส $0.50$ (คีย์เฟรม 3: Dynamic Apex, แขนกาง $68^\circ$, ทรงตัวกลางอากาศ)
       - **จังหวะทิ้งตัวลง ($vy < 0$):** เฟส $0.55 \dots 0.95$ (คีย์เฟรม 4: Descent Counter-Balance, แขนลดระดับลงมาอยู่ที่ $23^\circ \dots 28^\circ$, ขาเตรียมรองรับแรงกระแทก)
     - หาก `verticalVelocity == nil` จะส่งคืนเฟส Apex (0.50) เพื่อความเข้ากันได้ย้อนหลัง 100%
  2. ป้องกันปัญหาแขนหลุดเบ้าไหล่ (Shoulder Dislocation):
     - ใน `R6AnimationController.luau` เพิ่มเงื่อนไขตัดการเล่นแอนิเมชัน `jump` และ `fall` ของ Roblox เมื่อตัวละครอยู่ในโหมด Directional Jump
     - ขจัดปัญหาการหมุนแขนซ้อนกัน $110^\circ + 110^\circ = 220^\circ$ ที่ทำให้แขนบิดย้อนไปด้านหลังและหลุดลอย แขนทั้งสองข้างยังคงเชื่อมติดกับเบ้าไหล่ที่พิกัด $(\pm 1, 0.5, 0)$ แน่นหนา 100%
