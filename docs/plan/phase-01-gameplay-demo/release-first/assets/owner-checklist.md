## สถานะที่ผมตรวจเองแล้ว
1. [x] **Avatar:** ตัวผม ขนาดเท่าคนอื่น เสื้อผ้า/เครื่องประดับไม่บังเกม
2. [x] **Idle:** previewเท้าเอว/หันมอง/แตะเท้าผ่านแล้ว; ต่อชุด locomotion จริงแล้วตาม AGY และ Owner ทดลองรับฟีลชุดแรก แต่ technical findings ยังรอแก้
3. [x] **กล้อง/การเคลื่อนที่ 360° — Ownerรับฟีลล่าสุด:** เดิน/วิ่งหันตามทิศWASDทุกทิศ กล้องอิสระ Shiftวิ่ง32รอบทิศ หมุนมุมสั้น+หน่วงเลี้ยว ยืนนิ่งคงทิศตัว ไม่ตามเป้า; เป้าใช้เล็งยิง/ส่ง. ผ่านเฉพาะOwnerfeel ยังติดtechnicalRF-F46และRF-F42 (แบบhybridเดิมถูกแทนโดยOwnerQ1–Q4ล่าสุด)

   ผลเดิมที่เคยติ๊กผ่านเป็นประวัติของdraftก่อนหน้า Ownerบอกล่าสุดเกือบถูกแต่ยังไม่ตรง จึงเปิดตรวจข้อกล้องใหม่ (ไม่ลบผลทดสอบเดิม)
4. [x] **เดิน/วิ่ง:** ก้าวสัมพันธ์ความเร็ว เลี้ยวหยุดไม่ลื่นแปลก — Owner visual accepted
5. [x] **Sprint:** เร่งต่างจากเดิน คุมทิศ/หยุดได้ — Owner visual accepted; **Dash ยังไม่ได้ทำ** ตามรายงาน จึงไม่รวมเป็นผ่าน
6. [x] **กระโดด/ลงพื้น:** เลือกทิศ ลอยลงลื่น ไม่ค้าง — Owner visual accepted; ยังมี technical review เรื่อง lifecycle/land interruption
7. [ ] **เลี้ยง/รับบอล — กำลังทำ:** เท้าแตะสัมพันธ์บอล ไม่มี glue/วาร์ป/ดูดจากไกล คู่แข่งแย่งได้; ผมจูนกับ AGY
   **Owner เพิ่ม G + ท่าล็อคบอล (อนุมัติทำ / ยังไม่ผ่าน)**
   - [ ] กด G ค้างหันเข้าประตูคู่แข่ง เดินเลี้ยงช้า; W เข้าโกล/S ถอย/A-D เดินข้างโดยอิงประตู Shift ไม่เร่ง
   - [ ] ปล่อย G กลับวิ่งเลี้ยงปกติ; ไม่เปลี่ยนล็อกตัวกลางอากาศหรือดึงบอลจากคนอื่น/ระยะไกล
   - [ ] เปลี่ยนเข้าเฉียงเล่นท่าล็อคครั้งเดียว; W แล้ว S เกี่ยวกลับ; กดทิศค้างไม่เล่นท่าซ้ำและ W+S พร้อมกันหยุด
   - [ ] เล่นท่าจบก่อนเดินต่อ; ตาย/เสียโฟกัส/เปิดเมนูไม่ค้าง รอ Owner ตรวจ preview ก่อนผูกท่าในเกม
   **ข้อกำหนดเลี้ยงล่าสุด — Owner ยืนยัน 360 lead / self-lob (ยังไม่ผ่าน)**
   - [ ] จุดนำทางบอลตามทิศเดินทุกทิศ; หยุดแล้วนิ่งหน้าเท้าตามหน้าตัว คงการหันตัวเดิม
   - [ ] แตะออกด้านหน้าเป็นจังหวะตามความเร็ว ไม่ส่ายซ้าย–ขวา; กลิ้งตามระยะเคลื่อนจริง และไม่หมุนตอนนิ่ง
   - [ ] หักเลี้ยวเริ่มทันที หักกลับแรงลดความเร็วชั่วคราว ไม่รอจังหวะเข้าเท้า; ระยะจูนได้แต่บอลไม่ทะลุตัว/กำแพง
   - [ ] กระโดดขึ้นสำเร็จขณะครองบอลงัดหนึ่งครั้งแล้วปล่อยอิสระ; กันเจ้าของดูดคืนทันที ก่อนกลับรับได้ตามเกณฑ์ปกติ
   - [ ] ยังไม่รวมวอลเลย์/โหม่ง/จักรยานอากาศ; ไม่เปลี่ยนความสูง/เอน/โมเมนตัมกระโดดเดิม

   **เลี้ยงบอล — เกณฑ์ล่าสุด (Argon ทำต่อหลัง sync)**

   - [ ] Sprint เลี้ยง: บอลอยู่หน้า player เสมอระหว่างคุมบอล แตะ/เด้งนำไปข้างหน้าทีละนิด ไม่หลุดไปข้างหลัง
   - [ ] ตอนบอลเด้งนำและยังไม่ถึงจังหวะแตะ หักเลี้ยวจะหน่วง รอบอลเข้าเท้าจึงเปลี่ยนทิศจริงตาม input ล่าสุด
   - [ ] ยกเลิกกติกาหักเลี้ยว sprint แล้วเสียบอลอัตโนมัติ; เดินเลี้ยงหันฉับพลันยังคุมบอลได้
   - [ ] ปล่อยปุ่มหยุดได้ ไม่ถูกบังคับวิ่งต่อ และคู่แข่งยังแย่งบอลจริงได้
   - [x] กระโดดไม่กระตุกแล้ว — Owner ทดสอบยืนยันล่าสุด; ท่ากระโดด/เอนคงเดิม (ยังมี technical RF-F42 แยกจากฟีล)
   **กระโดดและการเอน — งานเพิ่มเติมในข้อ 7**

   **Owner ยืนยันล่าสุด:** ทดสอบแล้วไม่กระตุก — รับฟีลเฉพาะอาการนี้. ตรวจโค้ดยังติด RF-F42 จึงยังไม่ technicalpass/commit; งานเลี้ยงบอลและข้อ7โดยรวมยังไม่ผ่าน

   **ผลลองล่าสุด 27/10:** กรณีทั่วไปเหมือนหายกระตุกแล้ว เหลือกระโดดถอยหลัง/ไปคนละทิศกับหน้าที่ยังกระตุก — ยังไม่ติ๊กผ่านทั้งชุด ต้องคงล็อกทิศหันไว้

   **ข้อพบก่อน sync:** sprintjumpเคยระยะเท่าwalk; ต้องวัดซ้ำหลังแก้และไม่รับค่าจากconfigเป็นผลจริง

   **ผลก่อน sync (ประวัติ):** เอนไม่ได้/เลี้ยงยังไม่เสร็จ — review026. **ผลล่าสุดหลัง sync:** กระโดดและเอนได้ตามต้องการแล้ว แต่บางครั้งกระโดดกระตุกเหมือนไม่ขึ้น; ระบบเลี้ยงและข้อ7โดยรวมยังไม่ผ่าน

   - [ ] ล็อกทิศหันล่าสุดตอนออกตัวจนลงพื้น หมุนตัวกลางอากาศไม่ได้; กล้องหมุนได้ เอน4ทิศได้โดยไม่เปลี่ยนทิศหัน
   - [ ] กระโดดสูงขึ้น แนวตั้งค่อยๆช้าลงใกล้จุดสูงสุดแล้วตก ไม่ลอยค้าง
   - [ ] ระยะไปข้างหน้าตามความเร็วออกตัว: ยืน < เดิน < sprint; ไม่วาร์ป/เร่งบินกลางอากาศไม่จำกัด
   - [ ] เอนซ้าย/ขวา/หน้า/หลังและคืนกลางได้ มีค่าทิศเล็งเตรียมให้ยิง/ส่งใช้ภายหลัง
   - [ ] จูนผลต่อยิง/ส่ง/ปั่นตอนทำระบบนั้น ไม่ถือว่าทำแล้วตอนนี้
   - [ ] เคลียร์ technical locomotion findings ที่เกี่ยวข้องกับลงพื้น/sprint/lifecycle; ไม่สร้างpaneทดแทนงานเก่าที่ยังไม่ผ่านเอง

8. [ ] **ส่ง/ขอบอล:** เล็งเองตามทิศ/แรง ขอบอลเป็นสัญญาณไม่ส่งอัตโนมัติ
9. [ ] **ยิงตรง/โค้ง/วอลเลย์พื้นฐาน:** ชาร์จทิศ/จังหวะสัมผัสชัด พลาดได้ ไม่มี goalการันตี
10. [ ] **Dash/Stamina:** พุ่งคุมทิศ/เสียแรง/พักฟื้นชัด ไม่มีพุ่งตามเป้า
11. [ ] **Street combat/HP:** เตะกระตุกแต่บอลไม่หลุด; เสียบล้มบอลหลุด; จิ้ม/บล็อก/พุ่งชนธรรมดาเล็งเองพลาดได้
12. [ ] **HP/Stun/I-frame:** HPแยกจากชีวิต หมดแล้วstun1–1.5sฟื้น ไม่ตาย; ป้องกันโดนซ้อนสั้นๆ บอลยังแย่งได้; หลังหมดเตะคนเดิมซ้ำได้
13. [ ] **เกจ/Orb:** hitจริงนับครั้งเดียว ผู้ถูกเตะได้มากกว่า; Orbพื้น/อากาศ คนหรือบอลแตะเก็บได้ตาม last-touchจริง

- [ ] **ทุกท่าเล็งเอง:** ไม่มี homing/autoaim/goal100% ฝ่ายรับหลบหรือสกัดได้
- [ ] **Breaker Rush:** เวอร์ชันSuperของพุ่งชน กระเด็นชัดแต่ไม่ทะลุกรง/ค้างstun; ท่าพุ่งชนธรรมดายังมี
