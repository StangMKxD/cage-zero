# MODULE 04: `04-cards-animations-freekick` (การ์ดนักเตะหลาย Tier, อนิเมชันเบียว & ฟรีคิก FC27)

## 1. เป้าหมาย (Objective)
สร้างระบบการ์ดนักเตะหลาย Tier ที่เพิ่มปุ่ม Choice พิเศษในการดวล (พร้อมคูลดาวน์และบัฟต่อเนื่อง), ระบบกล้องคัตซีนดวลชนะสุดเบียว (1–3 ท่าตาม Tier), Easter Egg ท่าดีใจ และระบบยิงฟรีคิกสไตล์ FC27

## 2. เอกสารสเปกที่อ้างอิง (Referenced Specs)
- `docs/specs/spec-03-cards-rig-freekick.md`
- `docs/design/architecture-and-network.md`

## 3. ห้ามทำเกินขอบเขต (Out of Scope)
- ห้ามตั้งค่าสเตตัสของการ์ด Tier สูงให้ฉีกห่างจากการ์ดเริ่มต้นเกิน 15% (เน้นความต่างที่ Choice พิเศษและอนิเมชัน)

## 4. เกณฑ์ตรวจรับสำหรับ Codex (TDD Acceptance Criteria)
1. ชอยส์พิเศษของนักเตะดัง (เช่น เลี้ยงผ่าน 100% ของเมสซี่) ติด Cooldown ทันทีหลังใช้ และมอบบัฟ Boost ค่าส่ง/ค่ายิงตามเวลาที่กำหนดจริง
2. จำนวนอนิเมชันชนะดวลไม่เกิน 3 ท่าต่อตัวละครตามระดับ Tier
3. ระบบฟรีคิกคำนวณวิถีโค้ง (`Magnus Effect`) และการส่าย (`Knuckleball`) ตามจุดสัมผัสบอลที่ผู้เล่นเลือกได้จริง
